# VRCレンタルペットショップ

いつものVRライフにプラス1匹！

あなたのインスタンスに無言勢のペットキャストを招くキャスト出張型イベントです。

## Links

- Web: https://vrc-rentalpet.github.io
- X: https://x.com/RentalPetShop

## 画像の追加

写真・プロフィール画像は必ず `tools/optimize_images.py` で WebP に圧縮してから配置してください
（詳細は `hero-photos.js` / `cast-data.js` 冒頭のコメント参照）。

```bash
python tools/optimize_images.py hero --delete images/hero/新しい写真.png
python tools/optimize_images.py cast --delete images/新キャスト.png
```
